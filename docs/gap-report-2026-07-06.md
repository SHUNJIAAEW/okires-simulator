## 既知の限界・設計差（今後の検討事項）
1. **手数モデル**: 避難量は容量ベース。仕様の「1時間あたりの手数で避難を刻む」完全な手数制ではない（手数は死亡・表示に反映）。完全手数制はエンジンの大改修が必要。
2. **アセット会計の粒度**: 計画(コマ単位)と実行(便単位・切上)にズレが残る（往復輸送以前からの既存モデル性質。海自二重計上の主要ケースは修正済）。別リファクタで実便単位へ統一が理想。
3. **多良間/波照間の避難完了判定**: サブ島個別の住民数を持たず、内包エリア無人で近似。厳密化にはサブ島人口管理の追加が必要。
4. **臨時増援交渉の増援量**: 仕様に数値指定がないため控えめ固定(各+1・1回)。実運用値は調整可能。
5. **UI表示**: 波照間便・臨時増援・路線別停止の一部はイベントログ/避難記録経由。UIカードでの個別数値表示は未整備。
6. **港イベントの海路半減**: エリア単位倍率のため、同港経由の自衛隊海路にも当日波及（機雷ロジック流用）。
